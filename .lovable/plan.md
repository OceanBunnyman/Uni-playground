# 四人协作旅程游戏

## 目标
制作一个移动端优先的简约 2D 可交互演示。四位成员各自在独立路线前进，最终共同抵达终点；玩家可以用不打扰的方式看到并回应队友留下的动态。

## 体验结构
- **四人总览**：首页采用参考草图的四格地图，显示 A–D 的当前位置、路线进度和近期信号；点击任一格进入该成员视角。
- **个人地图**：以蜿蜒路径、柔和地貌和终点营地构成纵向地图；点击前方路径或方向控制让角色前进。
- **留下信号**：底部操作区提供“燃起篝火”和“埋下木桩”，分别表达“我遇到困难”和“我想分享收获”。
- **跨地图映射**：A 留下信号后，其他成员的地图会出现远处烟火、路牌或微光提示，并标注来源；玩家可点开查看，也可继续前进而不被打断。
- **平静回应**：查看后可发送“我看见了”“为你留盏灯”等轻量回应；不使用红点、倒计时、强提醒或失败惩罚。
- **演示循环**：内置四位成员与少量预设动态，所有操作在当前浏览器会话中即时生效，便于直接体验完整协作概念。

## 视觉与动效
- 手绘感的极简 2D 俯视地图，雾白、苔绿、湖蓝与篝火珊瑚色组合。
- 角色使用四种清晰轮廓与颜色区分；界面文字简短，工具感弱。
- 路径移动、篝火闪烁、远处信号浮现采用缓慢柔和动画，并尊重系统的减少动态设置。
- 针对手机竖屏设计，同时保证桌面预览中保持自然比例。

## 技术说明
- 使用 React 状态实现单机四人模拟，不接入账号、数据库或实时服务。
- 将地图、角色、信号与底部操作拆分为小型可复用部分；使用现有语义化颜色体系。
- 首页补充独立的标题、描述与社交分享元信息。
- 完成后检查手机与桌面尺寸的排版、主要点击流程和当前构建状态。
